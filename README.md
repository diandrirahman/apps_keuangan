# Full-stack App

Monorepo starter dengan React/Vite di `frontend` dan Express di `backend`.

## Menjalankan

1. Salin `.env.example` menjadi `backend/.env` dan isi `GEMINI_API_KEY` bila memakai AI.
2. Jalankan `npm install`.
3. Jalankan `npm run dev`.

Frontend: `http://localhost:5173` · API: `http://localhost:3000/api/health`
